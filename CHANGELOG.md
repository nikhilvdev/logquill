# Changelog

All notable changes to this project are documented in this file. The history of the
earlier releases is kept in `docs/legacy/python/CHANGELOG.md` (Python 0.3.0–2.0.0) and
`docs/legacy/js/CHANGELOG.md` (JavaScript).

## Unreleased

- Changed: the `develop` branch is now the 3.0 line. The Python library source was removed
  from it and replaced by a small Rust workspace (`logquill-core`, `logquill-cli`), the
  shared record schema and fixtures (`schema/`), and the plan, behaviour specification,
  publishing guide and API-name table (`docs/`). The 2.x Python releases remain on `main`
  and under the `v2.0.0` tag.
- Added: the shared corpus, `schema/corpus/` — 22 groups and 865 cases, generated by running
  the Python 2.0.0 release and the JavaScript source on one set of hostile inputs and
  applying the settled decisions — with the generator in `scripts/corpus/`, a scheduled check
  that the references still produce it, and a report of every place the two releases
  disagreed (`docs/spec/10-corpus-divergences.md`). Decisions D35–D45 record what was settled.
- Added: `logquill-core` reads and builds records, levels, timestamps and the `llm` block;
  writes Python-compatible canonical JSON; hash-chains, signs and verifies logs; applies the
  content-capture policy; and has the retry tracker and per-logger enable/disable rules. It
  passes the shared golden records, the golden chain and the corpus groups that cover them.
- Added: `logquill verify FILE [--sign-key HEX --signature HEX]` checks a hash-chained JSONL log
  and prints the same results as the Python command.
- Added: property tests for the record reader, the canonical JSON parser and chain verification.
- Added: the processing layer of `logquill-core` — trace-header and id parsing, key and PII
  redaction, JSON / text / logfmt lines, GenAI attributes and ECS documents, SQL and graph rows,
  the trace-tree builder, the sampling, rate-limit, adaptive-sampling, flight-recorder,
  run-summary and alert-dedupe state machines, and the log-call pipeline, which withholds a
  record when a redactor fails. All of it passes the shared corpus.
